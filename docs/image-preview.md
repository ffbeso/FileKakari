# 画像プレビュー

画像だけを複数選択すると、最大4枚を同時に表示します。2枚は横並び、3〜4枚は2列に配置します。5枚以上は先頭4枚を表示し、残りの枚数を見出しに表示します。画像以外を含む複数選択は対象外です。

## 操作

| 操作 | 動作 |
| --- | --- |
| 通常のホイール | 従来どおりファイルを移動 |
| 画像上で Ctrl＋ホイール | ポインター位置を基準に、その画像だけ拡大・縮小 |
| 拡大中に左ドラッグ | 画像を枠内で移動 |
| ダブルクリック | 全体表示と100%表示を切り替え |
| −／＋ | 画像中央を基準に縮小・拡大 |
| 全体 | 画像全体が収まる倍率へ戻す（小さい画像は拡大しない） |

操作対象の画像枠をアクセント色で表示します。画像枠をクリックしても一覧のファイル選択は変えません。選択内容が変わると倍率はリセットされます。最大倍率は800%です。

## 読み込み

選択後の待機は30msです。拡大直後は表示中の画像を使い、160ms操作が落ち着いてから必要な解像度を非同期で読み込みます。既存のデコード上限（800万画素）を維持するため、巨大画像では100%表示でも原寸解像度に達しない場合があります。選択変更時は古い要求をキャンセルします。

## 確認

回帰テストでは複数画像の独立した読み込み・破棄、失敗した画像との混在、倍率の独立性、ズーム基準点、移動範囲、サイズ変更後の位置と倍率を確認します。WPFの描画結果は回帰テスト出力の `image-tiles.png` に保存します。

実アプリでは次を手動確認してください。

- 1枚、2枚、3〜4枚、5枚以上の選択と、画像以外を含む選択。
- 通常ホイールとCtrl＋ホイールの使い分け、ドラッグ、ダブルクリック、各ボタン。
- 別の画像をズームしても他の倍率が変わらず、一覧の選択も変わらないこと。
- 高速な選択変更、Workspace／サブタブ切り替えで古い画像が戻らないこと。
- ウィンドウ縮小や異なるDPIのモニターへの移動時に画像が枠からはみ出さないこと。
